Gemini Decision 1 vs OpenAI's Decisions API (GPT-6 Luna) vs Jev vs Cloudflare Clef: which decision-model API to use for routing and classification (Nov 2026)

On Nov 11, 2026, Google launched the Gemini Decisions API and a new model, Gemini Decision 1 (gemini-decision-1). It doesn't write text. You send one input and a list of questions, and it returns a probability for each answer: yes/no, pick-one-of-N, or a score on a rubric. That makes Google the latest company with a "decision model", after TypeSafe's Jev, OpenAI's Decisions API on GPT-6 Luna and Cloudflare's Clef. Google AI Studio's launch post was one of the most-shared developer posts on X yesterday (about 36k views and 430 likes by early Nov 12). The question for builders: which one is cheapest for your routing, moderation or triage calls, and what does each one accept? We read Google's launch blog, the Gemini Decisions API docs and pricing page, OpenAI's Decisions guide and GA announcement, TypeSafe's model docs, Cloudflare's Clef docs, OpenRouter and Simon Willison's hands-on notes on the morning of Nov 12.

Quick verdict

You need audio, video or PDFs: use Gemini Decision 1. It's the only one of the four that reads all five input types (text, images, audio, video, PDFs) in one call, and it doesn't charge separately for transcription or OCR. $0.10 per million input tokens, nothing for output, and there's a free tier in AI Studio for prototyping. You send the same long prompt prefix on every call: look at OpenAI's Decisions API. Same $0.10 list price, but cached input is $0.01 per million. Gemini's Decisions API has no context caching, so a repeated prefix is billed in full each time. Your inputs are text (or text plus images) and you want the lowest bill: Jev is $0.042 per million input tokens, under half the price of Google or OpenAI. Its default context is smaller (64k per request). You already run on Cloudflare Workers: Clef runs inside Workers AI with zero data retention, but at $0.24 per million input tokens it's the priciest of the four, and it takes at most 64 questions per request. You need text out, extracted fields or multi-step reasoning: none of these. Google's own docs say to use a normal generative call with structured output for that.

What Google shipped on Nov 11

  • Three question types: noul (yes/no probability, always between 0.01 and 0.99), choice (2 to 255 options, with a probability for each) and score (an ordered rubric, returning a weighted score). Every answer also comes with a 0–1 confidence value, so your code can send unclear cases to a person or a bigger model
  • Up to 1,000 questions per request against one shared input, within a 262,144-token context window. Questions run in parallel and can't see each other
  • Speed: Google says 150–250 ms end to end, staying nearly flat from 1 to 100 questions (measured on inputs up to 16K tokens)
  • Billing: $0.10 per million input tokens on the paid tier, $0 for output. The shared input is billed once per request, however many questions you ask, and each question adds only its own instruction tokens
  • Gaps: no context caching, no Batch API, no Flex or Priority tiers. No YouTube or gs:// URIs. Question text must be plain text. It's only on the Gemini Developer API (v1beta, SDK 3.2+) for now; Google says Gemini in Google Cloud support is "coming soon"
  • Google's cost claim: across its shared benchmark suite, Google says Decision 1 is "nearly 5x cheaper" than running the same checks through Gemini 3.5 Flash-Lite. Google also says it leads its benchmark suite with the lowest calibration error. Both are Google's own numbers
  • Integrations rolling out: OpenRouter, LangChain, Vercel, LiteLLM, Pydantic AI, Pipecat, LiveKit and OpenCode

What a real workload costs

Every one of these bills only on input, so the math is simple: (tokens per call) × (calls) × (price per million). Take a support-ticket router where each call is about 1,000 input tokens (ticket plus a few questions) and you make 1 million calls a month, or 1 billion input tokens:

API1B input tokens / monthNotes
TypeSafe Jev$42Text and images only
Gemini Decision 1$100No caching, so no discount for a repeated prefix
OpenAI Decisions (gpt-6-luna)$100 uncached; less if most of each call is a cached prefixCached input $0.01/M, plus cache-write charges
Cloudflare Clef$240Before any Workers AI free allocation

For comparison, the same 1B tokens sent to OpenAI's gpt-6-luna as a normal text call is $100 in plus $0.50 per million for any output tokens, and you then have to parse the reply. The savings from a decision model come from no output tokens, many questions per call, and not having to parse text. The input price is the same.

Which to pick

  • Voice, call-center or video apps: Gemini Decision 1. You can pair a call recording with account data, or a scanned PDF claim with damage photos, in one request. Simon Willison's video test returned sensible probabilities (0.92 "robot", 0.05 "dragon"), though Gemini gives less extreme numbers than Jev or OpenAI, which both returned 1.0 or 0.0 on his yes/no tests
  • Agent tool selection or routing with a big, fixed system prompt: OpenAI, because cached input is a tenth of the list price. OpenAI's API also plugs straight into GPT-Live for voice apps
  • High-volume text classification on a budget: Jev. Read TypeSafe's own "jaggedness" notes first: it struggles with arithmetic, counting, dates and long, noisy inputs
  • Moderation at the edge on Cloudflare: Clef keeps data in your Cloudflare stack, but price it against Jev or Gemini before you go to production
  • Everyone: threshold on the confidence value, send low-confidence cases to a bigger model or a person, and test latency with your real input sizes. All speed claims here come from the vendors
