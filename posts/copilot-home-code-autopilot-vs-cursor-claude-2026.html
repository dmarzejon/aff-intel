Copilot Home / Code / Autopilot vs Cursor Projects vs Claude Cowork (Sep 2026)

On Sep 25 Microsoft reorganized the Copilot app into Home, Code, and Autopilot — a work-agent product surface for chat, delegated Cowork, NL-built apps, and a persistent named cloud teammate. This post is not about coding-IDE fleets (see Sep 25 cloud sessions), not model ranking (see Sep 23 Opus / GPT-6 picker), and not permission rails (see Sep 22 guardrails). Today’s buyer question: who should buy which seat when the goal is an always-on knowledge-work agent — Microsoft’s Home/Code/Autopilot stack, Cursor Projects, or Claude Cowork / Code.

Quick verdict

Microsoft 365 / Copilot shop: treat Home as the Chat + Cowork + Office-in-Copilot hub; budget USL for everyday Chat/Office and expect UBB (usage-based) for Cowork, Code, Autopilot, and frontier models — Autopilot is private preview expanding end of September, not GA. Cursor daily driver: keep Cursor Projects for IDE-native coordinator fleets; don’t buy a Copilot Autopilot seat solely because the homepage says “digital teammate” if your work is PR/repo-centric. Claude Pro / Max / Team: Claude Cowork (and Claude Code Projects) remains the Anthropic-native path for delegated knowledge work and parallel cloud threads — compare on workflow fit, not Autopilot naming. Do not: invent Autopilot GA or fixed Autopilot price numbers; don’t conflate Copilot Code (NL apps in M365 tenant) with GitHub Copilot IDE seats even though they share underlying tech.

What’s new (Microsoft Copilot, Sep 25 2026)

  • Home: Chat and Cowork together as the starting point; Office in Copilot embeds Word, Excel, and PowerPoint so drafts stay real editable files synced with the Office apps
  • Code: natural-language apps, dashboards, automations, and widgets — powered by the same underlying technology as GitHub Copilot; sandboxed; hostable in-tenant via Copilot Managed Runtime (preview)
  • Autopilot (formerly Scout): persistent, proactive named cloud agent with its own identity, memory, computer, and workspace; watches channels, follows up, runs recurring work; @mention in Teams / Outlook; cloud-hosted so it keeps working when you’re offline
  • Rollout: Home and Code start rolling to Frontier in the coming weeks; Autopilot expanding to private preview end of September; Code also preview for Microsoft 365 Premium / Pro later this year
  • Pricing signal: USL for everyday Chat and Office Copilot; UBB for Cowork, Code, Autopilot, and frontier models (e.g. Astra / Fable). FinOps for AI / Agent 365 cost management expanding to Code and Managed Runtime
  • Context stack: Microsoft IQ grounding; Fabric IQ for Power BI semantic models (GA in Chat/Cowork); Dynamics 365 / Power Platform grounding rolling to public preview; plugin registry rolling out

How to adopt without overbuying

  1. Already on Microsoft 365 Copilot — map Home (Chat/Cowork/Office) vs Code (NL apps) vs Autopilot (persistent teammate). Confirm Frontier / private-preview eligibility before budgeting UBB for Autopilot.
  2. Cursor daily driver — keep Cursor Projects for repo/PR fleets; only add Copilot seats if Office/Teams Autopilot is a real workflow, not a headline.
  3. Claude daily driver — stay on Claude Cowork / Code Projects unless you need Entra-governed Autopilot inside a Microsoft tenant.
  4. FinOps first — separate USL (everyday Chat/Office) from UBB (Cowork, Code, Autopilot, frontier models). Use Agent 365 / FinOps controls before turning on long-running agents.
  5. Don’t confuse posts — guardrails (Sep 22) ≠ model picker (Sep 23) ≠ Cursor Rollouts (Sep 24) ≠ overnight coding hosts (Sep 25) ≠ this Microsoft work-agent surface buy.
