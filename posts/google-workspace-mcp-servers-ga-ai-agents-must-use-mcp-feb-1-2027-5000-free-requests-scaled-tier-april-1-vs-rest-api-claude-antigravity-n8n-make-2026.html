Google Workspace MCP servers are GA, and from Feb 1, 2027 AI agents must use them instead of the Gmail and Drive REST APIs: what's free (5,000 requests a day), what the Scaled Tier costs from Apr 1, and what it means for Claude, Antigravity, n8n and Make (Nov 2026)

On Tuesday, Nov 24, 2026, Google made its Workspace MCP servers and the official Workspace CLI generally available, and attached two rules to them. First, a new Workspace AI Tools Addendum: "AI agents or similar access tools must use MCP to access Workspace data, rather than calling Workspace REST APIs directly. Technical enforcement begins on February 1, 2027." Second, a two-tier usage model for the Workspace APIs and MCP servers, with paid Scaled Tier billing starting April 1, 2027. We read Google's announcement, the Workspace developer docs on usage tiers, pricing, Gmail quotas and MCP setup, and the Addendum on the morning of Nov 26. If you only use Gemini inside Gmail, nothing changes for you. If you've wired an AI agent into Gmail, Drive or Calendar, or you sell one, this is your new deadline.

Quick verdict

You connect Claude, Antigravity or another agent to your own Gmail/Drive: the official route is now Google's hosted MCP servers, set up with Google's "Quick setup for personal use" (a Google Cloud project plus an AI-agent OAuth client). On the free Standard Tier you get 5,000 requests per day per product, and no billing account is needed. That's plenty for one person. You build or sell an agent that reads customers' Gmail, Drive or Calendar: plan the move from REST to MCP before Feb 1, 2027, mark your OAuth client as agentic, and price in Scaled Tier MCP usage, which is billed from the first request from Apr 1, 2027 (REST keeps large daily free allowances; MCP on Scaled has none). You run deterministic automations (no AI agent choosing the calls): Google says REST APIs remain the route for "deterministic app calls," and over 99% of active developers sit inside the free Standard Tier today. You just want AI in your inbox and docs: Google AI Pro (Gemini built into Gmail, Docs and Sheets) or Claude Pro (Claude in Docs, Sheets and Slides) are the no-setup options. Per user per day: 50 × 10 × $0.50/1,000 = $0.25; 200 × $0.50/1,000 = $0.10; 20 × $0.20/1,000 = $0.004. The searches are 70% of the units and the cost, so an agent that searches less and reads specific threads costs far less. Standard caps are per project, per product, so each user running their own project (the "personal use" setup) stays free.

Three Google CLIs, three jobs

  • Workspace CLI (new, GA Nov 24): lets a terminal agent read and change your Workspace data (mail, files, calendar) with scoped sign-in. Same tiers and quotas as above
  • Gemini API CLI (gemini-api, open source, Apache 2.0, beta): lets Claude Code, Codex, Antigravity or any shell agent call Gemini models and managed agents (images, voiceovers, file analysis, Deep Research) with a Gemini API key, billed at Gemini API rates. v0.5.0 (Nov 20) made Gemini 4 Hydrogen its default model. It went viral on X this week, but it isn't new: the current Go version has shipped since Sept 28
  • Antigravity CLI: Google's own coding agent. Antigravity users got a full Gemini quota reset on Thanksgiving morning

Who needs to do what

  • Individual Claude or Antigravity user: optional now. If you want Claude to search your Gmail or edit your Drive files, Google's MCP servers are the sanctioned connection and stay free at personal volumes
  • Agent builder (startup, indie SaaS): before Feb 1, 2027, switch Gmail/Drive/Calendar access from REST to MCP, tick "Use this client for an AI-powered agent" (is_agentic) on the OAuth client, keep non-agent features on a separate client, and re-run your unit economics with MCP billed from the first call
  • n8n, Make or Zapier-style workflows: fixed workflows that call Gmail or Drive the same way every time look like the "deterministic app calls" REST is meant for. Workflows where an AI agent node picks which Workspace calls to make look like what the Addendum targets. Google hasn't published a line between the two, so treat agent nodes as MCP-bound until it does
  • Workspace admin: check Admin console → Security → API Controls as the controls roll out; you can require human confirmation for sensitive agent actions and see agent audit logs
  • Cloud billing admin: watch for Google's email about affected projects; projects over Standard limits need Scaled (or the internal-use mark for REST) before Apr 1, 2027
