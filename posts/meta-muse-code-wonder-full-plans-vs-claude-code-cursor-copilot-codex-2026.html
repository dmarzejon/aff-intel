Muse Wonder Full is out: which Muse Code plan do you need ($5, $15, $50, or $200), and does it beat Claude Code, Codex, Cursor, or Copilot? (2026)

On Oct 12, 2026, Meta launched Muse Wonder and Muse Wonder Full, its most capable models so far. The @AIatMeta launch post passed 280,000 views. The pricing is split in a way that trips people up. Muse Wonder is on the Meta Model API at $4/$20 per million tokens and on every Muse Code plan. Muse Wonder Full is only sold by subscription inside Muse Code, on the $50 Power Usage plan or the new $200 Maximum Usage plan. The $20 and $100 plans for the Muse personal-agent app are a separate subscription, and they don't get you Wonder Full. On launch day, a quota bug burned through Muse Code limits too fast. Alexandr Wang said Meta fixed it the same evening and reset everyone's Muse Code limits, in a post that passed 349,000 views. We read Meta's launch blog, the Muse Code product and subscription pages, the Muse Wonder model page, Meta's Muse app subscription help page, CNBC's launch report, and the Claude, ChatGPT/Codex, X Subscription (Cursor), and GitHub Copilot pricing pages on the morning of Oct 15.

The Muse Code plans, and what each one unlocks

  • Everyday Usage, $5/month: Muse Spark, Muse Wonder, and Muse Image. 10–50 prompts every 5 hours, image and video uploads included, plus voice mode and web search
  • High Usage, $15/month: everything in Everyday, with 5x the usage and more multimodal inputs
  • Power Usage, $50/month: everything in High, plus Muse Wonder Full ("the most powerful Muse models"), 20x Everyday usage, early access to new features, and higher file uploads
  • Maximum Usage, $200/month (new Oct 12): everything in Power, with 80x Everyday usage. Meta's launch blog says it uses "the same five-hour and weekly resets"
  • Where the subscription works: only in the Muse Code CLI, signed in with your Meta Model API account. Any other API keys you create are billed pay-as-you-go. Meta's product page lists macOS and Windows
  • When you run out: upgrade, or wait for the refresh. Maximum users can only wait, because there's no paid overage on the subscription
  • Billing rules: upgrades take effect right away with a prorated charge. Downgrades start next cycle. There are no refunds on cancellation unless the law requires one, so cancel at least 24 hours before renewal

Muse Wonder vs Wonder Full vs the Muse app

  • Muse Wonder (API): muse-wonder-1.0, 1M-token context. $4 per million input tokens, $20 per million output tokens, $0.20 per million cached input tokens. That's the same list price as Claude Opus 5.5 on Anthropic's pricing page ($4/$20). Contributor mode isn't available for Muse Wonder on the API. Meta says Wonder "brings comparable performance to Muse Wonder Full"
  • Muse Wonder Full: 1M context, subscription-only in Muse Code (Power or Maximum). Meta says it tops DeepSWE and SWE-Marathon "in independent third-party runs." Those are vendor-reported numbers, so test it on your own repo
  • Muse app (personal agent): a separate subscription at muse.ai or in the mobile app. Power is $20/month for 500M Muse tokens a week, and Maximum is $100/month for 3B tokens a week. CNBC reports that app users need one of these plans to use Muse Wonder, and that Wonder Full is limited to the $50/$200 Muse Code plans. Meta says the app subscriptions are "in limited testing" and not available everywhere yet
  • Contributor mode (Muse Code): on by default. You get more usage per plan in exchange for letting Meta use your content (prompts, code, files, and responses) to train future models. You can switch it off in settings at any time

Checklist before you pick

  1. Decide whether you need Wonder Full or just Wonder. Meta itself says Wonder is comparable. Start on Everyday ($5) or the API, and move to Power ($50) only if Wonder isn't good enough on your tasks.
  2. Turn off Contributor mode for work code. It's on by default and trades your content for more usage. Check the setting before your first session on a private repo.
  3. Don't buy the Muse app plan for coding. The $20/$100 app plans are a different product and don't include Wonder Full.
  4. Compare at the same price. At $50 you're between Claude Pro ($20) and Claude Max ($100). At $200 you're level with Claude Max 20x, ChatGPT Pro $200, X Subscription Ultra, and Copilot Max ($100 plus credits). Run the same task in Claude Code or Codex before you commit.
  5. Mind the no-refund policy. Upgrade mid-cycle (prorated) instead of buying Maximum up front, and cancel at least 24 hours before renewal if you're only testing.
  6. Watch the limits for your first week. Launch day had a quota-counting bug, which Meta says is fixed. If your usage still drains unusually fast, screenshot it and contact support before you upgrade.
