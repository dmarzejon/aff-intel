How to adopt without over-buying

  1. If you are a Salesforce customer — request / enable Salesforce in Claude beta; connect once as admin so permissions inherit org-wide.
  2. Keep Claude Pro for non-CRM work — Claudeforce grounds Claude in Salesforce; it does not replace general writing, research, or Cowork-style personal agents.
  3. Pick your primary surface — Claude (Claudeforce), Slack (Slackforce), or Lightning (Coworker). Same Headless 360 backbone; don’t run three pilots without an owner.
  4. Treat Koa as Agentforce infra — CRM reasoning model for agents (pilot → US winter 2026 GA), not a seat you buy like Claude Pro.
  5. Coding stays on Cursor — Salesforce Dev plug-in for Claude Code is for builders; day-to-day shipping agents still belong in an IDE.
