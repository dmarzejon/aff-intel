One Claude: Docs, Slides & Cowork in one chat (Sep 2026)

On Sep 16, 2026, Anthropic folded Claude Chat and Claude Cowork into a single interface — One Claude — and launched beta Claude Docs and Claude Slides, with Claude Design available inside every conversation. You no longer pick Chat vs Cowork up front; Claude picks tools from your context, skills, and connectors. Here’s when to upgrade to Claude Pro/Max, stay on ChatGPT Work / Gemini Docs, or keep coding on Cursor.

How to adopt without over-buying

  1. If you already pay for Claude Pro/Max — try Docs and Slides on the next brief or deck; keep autonomy on ask-before-act until you see usage.
  2. If you’re Free — wait for the later wave, or buy Pro only if you need Claude-native collab this month (not just chat quality).
  3. If Drive / M365 is the file of record — stay on Gemini or Copilot for the canonical doc; use Claude for reasoning and paste/export when it wins on quality.
  4. Watch token burn — agentic Cowork-style runs can consume orders of magnitude more tokens than chat; Max makes sense if Docs/Slides become daily.
  5. Coding stays on Cursor — One Claude does not replace Claude Code or an IDE for shipping.
