Google Cloud spend caps are GA for the Gemini API, and DeepSeek's Search and Fetch calls now cost money: how to cap your AI API bill (Nov 2026)

Two billing changes landed over the weekend, and both matter if you run agents on pay-as-you-go APIs. On Oct 30, Google announced that spend caps on Google Cloud Budgets are generally available, covering the Gemini API, Gemini Enterprise Agent Platform (formerly Vertex AI), Cloud Run and Cloud Run functions. A cap pauses new requests to one service in one project once estimated spend passes the amount you set, and it now resets on its own at the start of each month. On Nov 1 (00:00 Beijing time, noon ET on Oct 31), DeepSeek's Search and Fetch APIs stopped being free for calls made through DeepSeek Harness, Claude Code and Codex. Each now bills $0.75 per 1,000 successful requests. We read Google's and DeepSeek's pages on Nov 3.

Quick verdict

You call the Gemini API from a Google Cloud project: set a spend cap on your test and sandbox projects today. It's the first hard stop Google offers for Gemini, and it no longer needs a manual unlock every month. You run production traffic on Gemini: cap it too, but set the amount well above your normal month. When a cap triggers, new requests fail until you lift it or the month rolls over. You point Claude Code or Codex at a DeepSeek API key: your agent's web searches and page fetches now come out of your DeepSeek balance. Check usage this week. The price is low per call, but agents call these tools a lot. You're on a flat subscription (Claude Pro, Max, Ultra or ChatGPT Plus, Pro): neither change touches you. Subscriptions bill a fixed price and stop you with usage limits instead.

What Google changed on Oct 30

  • Spend caps are GA. Google's billing release notes list GA "for a limited set of services" on Oct 13; the Oct 30 blog post announces general availability with three additions
  • A spend caps API on the existing Cloud Billing Budgets API, so you can create, lift, update or delete caps from code, for example on every new sandbox project
  • Live cost reports: Google says caps for AI services "trigger within minutes of usage using estimated, live costs," and Cost Reports now show those estimated costs
  • Automatic monthly resets: an enforced cap lifts at the start of the next month and paused services resume. You can still lift a cap by hand mid-month
  • Eligible services: Gemini API (generativelanguage.googleapis.com), Gemini Enterprise Agent Platform (aiplatform.googleapis.com), Cloud Run and Cloud Run functions
  • Alerts: sent by default to billing administrators and project owners at 50%, 80% and 100% of the cap

What a spend cap doesn't do

  • It isn't instant. Google's docs say enforcement "isn't instant and any cost overages are billed as normal." Requests already running aren't stopped
  • One project, one service, one month. Folders, organizations, labels, and multi-project or multi-service budgets are out of scope. The period is always a calendar month
  • Gross costs. Caps count estimated gross spend, so free credits and savings don't stretch them
  • Provisioned Throughput keeps running, and subscription costs (such as Gemini Enterprise) and fixed costs like storage are out of scope
  • Resellers are excluded. Caps are for first-party Google Cloud billing accounts only
  • Recovery can lag. A dev.to writeup of the GA notes says services might take up to an hour to return to normal after a cap is lifted

What DeepSeek changed on Nov 1

  • Price: Search and Fetch each cost $0.75 per 1,000 successful requests, billed separately from model tokens and from each other
  • What counts: only an HTTP 200 response with a result, meaning a non-empty results array for Search or page content for Fetch. Failures, empty results and timeouts are free. Asking for more results per search (1 to 50) doesn't change the price
  • Who it hits: anyone calling /v1/tools/search or /v1/tools/fetch directly, and anyone running Claude Code, Codex or DeepSeek Harness on a DeepSeek API key, because DeepSeek says those tools' server-side web calls "already hit the Search and Fetch APIs"
  • Where it's charged: from your prepaid DeepSeek balance, with any granted (bonus) balance used first
  • Rate limits: 100 requests a second for Search and 25 for Fetch, per account, with an extra per-domain limit on Fetch

The per-task math

At $0.75 per 1,000, one successful call costs $0.00075. A coding agent that runs 10 searches and 5 page fetches on a research-heavy task spends about $0.011 on tools for that task. At 1,000 such tasks a day, that's about $11 a day, or roughly $340 a month, before any model tokens. At 50 tasks a day it's about $17 a month. These are our example numbers, not DeepSeek's; your agent's call counts are what matter, so log successful Search and Fetch calls separately from token usage.

A 10-minute checklist

  1. In Google Cloud, open Billing > Budgets & alerts and add a spend cap budget for the Gemini API on each sandbox or test project. Start low
  2. For production, set the cap above a normal month and make sure the billing admin and project owner roles go to people who will see the 50% and 80% alerts
  3. If you create projects from scripts, add a spend cap through the Budgets API at creation time
  4. On DeepSeek, check your usage page for Search and Fetch lines since Nov 1, and top up based on what you see, not on last month's balance
  5. If your agent searches before every answer, cap it per task in your own code, or switch it to a fixed-price plan for interactive work

When a flat plan beats pay-as-you-go

A spend cap stops a runaway bill, but it does it by stopping your app. If most of your use is one person working interactively in Claude Code, Codex or Gemini, a subscription caps the bill by design: you hit a usage limit, not an invoice. Claude Max is $100 a month and Ultra $200; ChatGPT Pro comes in $100, $200 and $500 tiers. See our Claude Ultra vs ChatGPT Pro 200 guide and our post on the API credits those plans include. Keep pay-as-you-go, with a cap, for automated jobs that run without you watching.
