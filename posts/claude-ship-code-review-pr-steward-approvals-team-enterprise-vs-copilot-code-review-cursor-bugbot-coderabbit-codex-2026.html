Quick verdict

Solo dev on Claude Pro, Max or Ultra: update Claude Code (v2.1.330+) and try /ship on your next branch. It opens the PR, reviews it, then keeps fixing failing checks and comments. It runs in your session and counts against your normal Claude Code usage, with no separate bill. Team or Enterprise admin: Claude Ship's real advantage is the loop. PR Steward fixes red CI, merge conflicts and review comments, and Approvals signs off by a policy file. Rivals have pieces of this: Copilot does review and approvals, Cursor has Bugbot Autofix plus a PR Routing & Approval automation, and CodeRabbit's Team plan has a CI fixer and conflict resolution. But Claude's review is the expensive one: Anthropic's published average is $15–25 per review, billed on top of seats. Turn it on for one critical repo, set Once after PR creation (new repos default to After every push), and set spend limits first. PR Steward has no spend limit until you set one. Cost-sensitive team that just wants a reviewer: Copilot code review Balanced (~$1.50 a review, approvals GA), Cursor Bugbot (~$1.00–1.50 a run) or CodeRabbit Essentials ($24 per PR author per month, annual) cost a fraction of the price per PR. Already pay for ChatGPT Plus or Pro: Codex GitHub review is included. Turn it on before you buy anything else.

What Claude Ship actually is

  • Code Review (generally available since Oct 15): reviews each PR against the codebase, verifies its findings adversarially and posts inline comments ranked by severity. Admins pick Quick, Standard (default) or Deep per repository. Anthropic says most reviews take 6–10 minutes
  • PR Steward (public beta): works on failing CI checks, merge conflicts and review comments, whether they come from Code Review, other review bots or people. It pushes commits and comments with what it changed and how to undo it. It's designed never to approve or merge. Steer it with @claude, start it with @claude steward, stop it with @claude stop
  • Claude Approvals (public beta): a check driven by a policy file, .claude/approvals.yml, that says how many people each path needs and where Claude may approve. Anthropic calls it "a smarter CODEOWNERS file." It can use Code Review's findings or your own natural-language classifiers. Anthropic recommends starting in observe mode, which is still billed
  • /ship (rolling out in the Claude Code CLI and desktop app): commits your change if needed, opens the PR, reviews it with /code-review, then "watches" the PR and pushes fixes until it's ready. You merge it. /steward skips the review on an already-open PR. It needs Claude Code v2.1.330+, GitHub CLI 2.63+ signed in, and git 2.38+. It doesn't run in cloud sessions
  • Where it works: GitHub repositories only. The org agents aren't available to organizations with Zero Data Retention, the HIPAA configuration or customer-managed encryption keys

Setup checklist if you turn it on

  • Change the review trigger. A repo you add starts at After every push, which multiplies the cost by your pushes per PR. Start with Once after PR creation or Manual (@claude review). Drafts and fork PRs are skipped automatically
  • Set three limits: Code Review's monthly spend limit, PR Steward's monthly limit and per-repo cap (start Steward on Manual), and the Approvals classifier limit. All live in Organization settings > Usage
  • Billing keeps going with usage credits switched off, per Anthropic's docs. To stop it, turn the agents off, and turn Approvals off before Code Review, because a policy file can start billed reviews
  • Already on Code Review? Adding .claude/approvals.yml changes which PRs get reviewed automatically. Add claude/code_review to a rule to keep reviews you want
  • Auto-merge warning: with GitHub auto-merge or a merge queue and a policy that doesn't require a person, a change can merge with nobody acting. Keep branch protection requiring a human on sensitive paths

Which to pick

  • You live in Claude Code already (Pro, Max, Ultra): use /ship. It costs nothing extra, and it's the easiest way to test the fix-until-green loop
  • Claude Team or Enterprise with agent-written code piling up: Claude Ship is the most complete review, fix and approve loop right now. Budget for it like API usage, not like a seat
  • GitHub-first team watching cost: Copilot code review on Balanced with approvals on routine paths. Use Max (~$10) only on risky PRs. Compare models in our Copilot guide
  • Cursor team: you already have the same three pieces: Bugbot (usage billing on Premium and Teams), Bugbot Autofix, and PR Routing & Approval. See Cursor's security review vs Copilot and Claude
  • Mixed tools, predictable bill: CodeRabbit charges per PR author, not per review, and only people who open PRs count as seats
  • ChatGPT Plus or Pro subscriber: switch on Codex review first. It only posts P0/P1 findings, which keeps it quiet
