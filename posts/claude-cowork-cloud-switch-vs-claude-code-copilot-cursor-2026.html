Claude Cowork goes cloud on Oct 6: stay with Cowork, move to Claude Code, or run Copilot / Cursor locally? (2026)

Anthropic’s Help Center says that on October 6, 2026, new Claude Cowork tasks on Pro and Max plans run in the cloud, and the “Only on your computer” option in Settings → General is removed. Tasks you already started on your computer stay there until they’re done. This is not the Sep 17 One Claude / Docs / Slides post (that was the chat + Cowork merge), and not the Sep 25 Claude Code cloud sessions post (where coding agents run). Today’s buyer question: if you relied on Cowork staying local, do you accept cloud Cowork, move that work to Claude Code desktop, or put local desktop automation on GitHub Copilot or Cursor?

Quick verdict

Your Cowork tasks only use connectors, web search, and files saved in your Claude account: accept cloud. Those tasks keep running with the laptop closed, and scheduled tasks run with no device online. Your tasks touch local folders, the browser, or computer use: the cloud session still needs Claude Desktop open on that machine, so you mostly get the cloud trade-offs without the “laptop closed” benefit. Decide today which ones should move to Claude Code desktop, which Anthropic itself names as the local option. Team / Enterprise: the Oct 6 notice is written for Pro and Max. Team has “Run Cowork in the cloud” on by default and an owner can turn it off. Enterprise has it off by default. Do not: assume your projects and scheduled tasks carry over to Claude Code (Anthropic says they don’t). Don’t expect cloud sessions to reach local files when Desktop is closed. And don’t invent a new price: Anthropic announced no plan or price change with this switch.

What changes on Oct 6 (Pro & Max)

  • Cloud by default: new Cowork tasks run on Anthropic’s servers, and sessions and files are saved to your Claude account. “Only on your computer” disappears from Settings → General, and there’s nothing to set up
  • In-flight local tasks: they stay on your computer until finished. Each one shows a note with a button to download its transcript so you can continue in Claude Code
  • Scheduled tasks move to the cloud too: that includes ones that use files on your computer, and those still need the desktop app open to run
  • Local folders: they stay on your machine. Claude reaches only folders you’ve connected, only through the open desktop app, and fetches a copy of just the file a task needs. Deleting a session deletes those copies (per Anthropic’s retention practices)
  • Desktop-only reach: local file access, local connectors and plugins with local MCP servers, browser use, and computer use still need the Claude Desktop app open, even when the session runs in the cloud
  • Escape hatch: Anthropic points work that “has to stay on one machine” to Claude Code in the desktop app, which runs on your computer and keeps folders and history there. Projects and scheduled tasks don’t carry over
  • Status: Cowork in the cloud is labeled beta, and some features aren’t available yet on every surface. No beta-exit date is given

Checklist before Oct 6

  1. Inventory scheduled tasks. Open Scheduled in Claude and sort tasks into two groups: those that use only connectors, web search, and account files (fine in the cloud) and those that need local folders or the browser (Desktop must stay open).
  2. Download transcripts for any local task you’ll want to keep or move. The note on each local task has a download button, and Anthropic also offers a full Cowork history download from the in-app notice.
  3. Move “must stay local” work to Claude Code desktop. Recreate projects and schedules by hand, because they don’t carry over.
  4. Review privacy settings. Training use follows Settings → Privacy → “Help improve our AI models.” Cloud sessions process the files they open on Anthropic’s servers.
  5. Org admins: check Organization settings → Cowork → “Run Cowork in the cloud,” network-access policy, “always allow” approvals, and trusted-device requirements before members start relying on cloud sessions.
  6. Need local GUI automation outside Claude? Pilot Copilot Computer Use or a Cursor Self-Hosted worker on one non-sensitive workflow. Don’t buy a second seat just to stay local.
