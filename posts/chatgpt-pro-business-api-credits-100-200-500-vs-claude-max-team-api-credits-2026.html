ChatGPT Pro and Business now include $100–$500 a month in OpenAI API credits: how it compares with Claude Max and Team, what it covers, and what $200 actually buys (2026)

On the evening of Oct 28 (7:17 PM ET), @OpenAIDevs announced that "eligible ChatGPT Pro and Business subscribers can claim up to $500 per month in API credits to build apps and agents." Pro 100, Pro 200, and Pro 500 get $100, $200, and $500 a month, the same as their price. Business gets $20 per paid Standard seat and $100 per paid Premium seat, pooled and capped at $500 per workspace. That's the same structure Anthropic launched for Claude Max and Team on Oct 7, down to the per-seat numbers and the $500 cap. The catch is the same, too: the credits are for the API only. They don't add to your ChatGPT or Codex usage, and OpenAI says they don't cover Codex used with an API key. That matters this week, because grandfathered Pro 200 subscribers drop from 20x to 10x the Plus allowance on Friday, Oct 30. We read OpenAI's Help Center and developer docs and Anthropic's credit pages on the morning of Oct 29.

Quick verdict

You're on Pro or own a Business workspace: claim it. It's free and doesn't need an API payment method. Once your paid plan is at least seven days old, go to Settings > Billing in ChatGPT and find the API credits benefit, or start from Billing on the API Platform. Pick the API organization carefully, because you can link only one and changing it means contacting support. You're a grandfathered Pro 200 user hoping it offsets Friday's cut: it doesn't, at least not for Codex or ChatGPT Work. The $200 goes to an API organization, not to your weekly allowance. It only helps if you'll move some work to your own scripts or apps on the API. You already pay an OpenAI API bill each month: this is the real winner. Pro 100 at $100 now comes with $100 of API spend, so if you'd spend that much anyway, the chat plan costs you close to nothing extra. You're on Plus: nothing for you. Plus isn't eligible, and free trials don't count. You're choosing between ChatGPT Pro and Claude Max at the same price: the credit is now a wash ($100 vs $100, $200 vs $200). Decide on models, limits, and which API you'd build on.

What OpenAI launched (Oct 28)

  • Amounts: Pro ($100 tier) $100, Pro ($200 tier) $200, Pro ($500 tier) $500 per monthly billing period. Business: $20 per paid Standard seat and $100 per paid Premium seat, pooled, capped at $500 a month. OpenAI's examples: 5 Standard + 3 Premium seats = $400; 10 Standard + 4 Premium = $600 before the cap, so $500
  • Annual Business: workspaces billed annually up front get the whole year's grant at once, capped at $6,000, expiring at the end of the annual cycle
  • Who's eligible: Pro 100, Pro 200, Pro 500, and Business workspaces with paid Standard or Premium seats. Not eligible: Plus, free trials, complimentary subscriptions, Enterprise, Edu, and legacy Codex seats. OpenAI also says availability "depends on the enabled cohort and country"
  • Waiting period: the paid subscription must be active for at least 7 days. The first grant is prorated for what's left of your billing period, so claiming mid-cycle gets you less than the full amount
  • Who can claim: the owner of the Pro subscription or Business workspace, who must also own the receiving API organization, using the same email on both. Being a Business admin or member isn't enough. New to the API? You can link your Personal API organization
  • Covered: paid API Platform usage in the linked organization, including the Responses and Chat Completions APIs, the Agents API (including OpenAI-hosted sandbox charges), the Decisions API, GPT-Live and the Realtime API, the Images API, and built-in tools such as web search, file search, and Code Interpreter
  • Not covered: "Codex usage through API keys." The credits also "don't increase your ChatGPT or signed-in Codex usage limits," your personal usage-credit balance, or a Business workspace's credit balance
  • Mechanics: granted automatically at each renewal after you activate once. Expires at the end of each billing cycle with no rollover. Spent before any API credits you bought. Rate limits still apply. When it runs out with no purchased credits left, requests fail with HTTP 429 credit_balance_exhausted
  • Plan changes: upgrading Pro gives extra prorated credits for the rest of the cycle. Cancelling doesn't revoke credits already issued; they last to the end of the cycle. Downgrading to Plus, Go, or Free removes the link at the end of the cycle. An approved full refund removes the unused credits tied to that charge. OpenAI says the benefit "may change or be removed in the future"

Checklist before you claim

  • Pick the organization once. One subscription links to one API org, and one org takes only one link. If you have a work org and a personal org, decide which one you'll actually build in
  • Match emails. Sign in to the API Platform with the same email as your ChatGPT account, and make sure you're an Owner of the org
  • Claim early in your billing cycle if you can. The first grant is prorated, and the balance expires at the end of every cycle
  • Watch who has keys. Everyone with a key in the linked org spends the same balance. Set project budgets before you share keys
  • Don't add Auto Recharge by reflex. Without a payment method, requests just stop at zero with a 429. With Auto Recharge, they keep going on your card
  • Business owners: teammates need API organization and project access separately. A ChatGPT seat doesn't grant it

Which to pick

  • OpenAI-first builder already paying for the API: ChatGPT Pro 100 now pays for itself if your API bill is at least $100 a month

  • Small team on ChatGPT Business: two Premium seats bring $200 a month into one API org, and five bring $500. Good for an internal agent or prototype without a separate API budget line
