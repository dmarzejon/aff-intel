JetBrains Air in IDEs: one place to run Codex, Copilot, Claude and Junie, or stay on Cursor / Copilot / Claude Code? (2026)

JetBrains has opened the Early Access Program for Air in JetBrains IDEs (blog post dated Oct 1, 2026). It comes as a plugin on JetBrains Marketplace or built into the 2026.3 EAP builds, and the docs say it works with IntelliJ-based IDEs from 2026.2. JetBrains is clear that Air “is not an AI provider, and it ships with no agents installed.” It is a tool window that finds the agents you already have, such as Codex, GitHub Copilot, Claude Agent, Gemini, Junie, and other ACP-compatible agents, and runs them in parallel sessions inside the IDE. This is not the Sep 24 Cursor Rollouts post or the Sep 28 Copilot Home/Code/Autopilot post. Today’s buyer question is different: if you already pay for one or more agents, should a JetBrains IDE be the place where you run them all, or should you stay in Cursor, Copilot, or Claude Code?

Quick verdict

You live in IntelliJ IDEA, PyCharm, WebStorm, or another IntelliJ-based IDE and already pay for Claude, Copilot, or an OpenAI/Codex account: try Air. JetBrains says you don’t need a JetBrains AI subscription to use your own agents, and with a third-party subscription your data goes straight to that provider, not through JetBrains. You want one editor where AI is the product: Cursor is still the simpler choice. Air is an EAP, and JetBrains warns about UI changes and rough edges. You want agents that keep running with the laptop closed: Air cloud runs currently need a JetBrains AI subscription (the EAP post says “available to orgs with AI seats”). If you don’t have that, Copilot’s cloud agent or Claude Code cloud sessions cover the same need. Do not: install Air from the AI Assistant notification without knowing what happens: that path turns off AI Assistant (you can turn it back on in Settings | Plugins). And don’t expect “free” to mean unlimited. Free Junie Lite runs need a JetBrains Account, and JetBrains says terms and models may change. No Air price has been announced.

What JetBrains actually shipped

  • Bring your own agents: Codex, Gemini, GitHub Copilot, Claude Agent, and Junie work out of the box, and other agents connect through ACP. Air finds compatible agents on your machine and connects them with one click, and you can add more from an agent registry
  • Claude subscription supported: run Claude Code with your Claude subscription in Air’s terminal and full-screen IDE tab, signing in the same way you would in any terminal
  • Sessions instead of a chat: parallel agent sessions across projects in one view, showing activity, unread updates, changed files, outgoing commits, and cost per session
  • Worktrees: start a session from any branch, on a new branch or detached, in a temporary worktree, then cherry-pick the result back
  • IDE intelligence for agents: built-in IDE skills and tools for debugging, profiling, database exploration, and semantic code search. JetBrains says this can mean fewer tokens on some tasks
  • Review in place: open diffs from a session, leave notes on specific diff lines for the agent, send your local changes to an agent for review, and resolve merge conflicts with an agent
  • Presets: save an agent, model, effort level, and access level under a name and reuse it
  • Flexible billing: use your provider subscription, an API key, or a base URL, or use JetBrains AI with credits billed at public API rates. You can switch subscriptions mid-session
  • Privacy defaults: with no agents signed in, nothing leaves your machine, and Air needs no login until you start an agent. Turning off the plugin changes nothing else

Checklist before you switch

  1. Check your IDE version. The plugin needs IntelliJ-based IDEs 2026.2 or later. The 2026.3 EAP builds include Air natively.
  2. Install from Marketplace if you want to keep AI Assistant. The docs say the standalone plugin doesn’t replace or turn off AI Assistant. The AI Assistant notification path does turn it off.
  3. List the agent subscriptions you already pay for. If you have Copilot, Claude, and Codex, Air can run all three, so don’t buy a new seat just to try it.
  4. Run one parallel task with worktrees. For example, have Junie Lite (free) and your paid agent each fix the same bug on separate branches, compare the diffs and session costs, then cherry-pick the winner.
  5. Decide on cloud on purpose. Cloud runs need a JetBrains AI subscription and JetBrains says rollout is gradual. If you already get cloud runs from Copilot or Claude Code, you may not need a second cloud.
  6. Org admins: look at Air Governance (AI access, policies, usage, spend) before developers bring personal agent subscriptions into company repos.

Recommendation

  • JetBrains user paying for two or more agents → install Air from Marketplace this week and run them in parallel sessions. It costs nothing extra with your own subscriptions
  • JetBrains user with no AI subscription → try free Junie Lite runs first, then add Copilot or Claude Pro if a paid agent wins your side-by-side test
