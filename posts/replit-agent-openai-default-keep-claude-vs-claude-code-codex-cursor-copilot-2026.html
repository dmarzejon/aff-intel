Replit Agent now defaults to OpenAI: how to keep using Claude, what Core and Pro get you, and when Claude Code, Codex, Cursor, or Copilot is the better buy (2026)

Onstage at TechCrunch Disrupt on Thursday, Oct 15, Replit CEO Amjad Masad said Replit was "no longer working with Anthropic." On Oct 17 he walked that back on X: "Replit remains model agnostic. Our users can choose Anthropic models as well as many other supported models. What I meant at TC Disrupt is that OpenAI is now our preferred partner powering Agent based on performance, cost, and strength of our partnership." That post passed 64,000 views, and TechCrunch's post about the story on X passed 143,000. So the real change is this: OpenAI's models are now the default behind Replit Agent, and Claude is something you have to pick yourself. TechCrunch notes that most customers stick with the default, and a person familiar with the Anthropic side told TechCrunch the partnership is still in place. Below is what that means for your plan. We read TechCrunch's report, Masad's posts, Replit's pricing page, and Replit's docs on plans, Agent modes, the Model selector, AI billing, and Enterprise model controls on Oct 18–19.

Quick verdict

You're on Replit Core or Pro and want Claude: you can keep it. Switch Agent to Power or Max mode and pick a Claude model by name under Primary model. Don't leave it on Auto, because Auto lets Replit choose the model, and Replit now prefers OpenAI. You're on the free Starter plan: you can't choose a model at all. Free Mode always uses Replit's automatic routing. Choosing a model starts at Core, $20/month ($18/month billed annually). You came to Replit mainly for Claude and you're comfortable in a repo and terminal: Claude Pro ($20, or $17/month annually) includes Claude Code and Opus. Keep Replit only if you need its hosting, database, and one-click publishing. You're happy with OpenAI models: the Replit default now does that for you. Or go direct with ChatGPT Plus ($20) for Codex. But Codex users spent the weekend reporting that their usage limits drain unusually fast (details below). You want one editor with every model: GitHub Copilot Pro ($10) lists Claude Opus 5.5, GPT-6.1 Sol, and Gemini 4 Argon. Cursor is now sold through The X Subscription (Premium $30), where Claude and GPT bill at API list price.

What changed at Replit (and what didn't)

  • The default: OpenAI is now Replit's "preferred partner powering Agent." Masad told TechCrunch it came down to "performance, economics, and the strength of our partnership," and said OpenAI's Sol and Astra models "consistently" do better on Replit's internal and public benchmarks for building apps from scratch. He didn't give scores
  • Cost was a reason: asked on X whether picking Claude costs the same as the OpenAI default, Masad replied: "OpenAI models are generally more affordable." Replit Agent uses effort-based pricing: each request is billed by its complexity, and we found no per-model price list in Replit's docs. So check what a Claude request costs on your own usage dashboard, rather than assuming it costs the same
  • Still available: Claude models are still in the Model selector (list below). Masad: "Our users can choose Anthropic models as well as many other supported models"
  • Disputed: per TechCrunch, Replit was until recently a top-five Anthropic customer, and a late-September Replit blog post still listed Claude Fable 5 and 5.1 running in Agent production. A person familiar with the Anthropic side said the partnership is still in place. Anthropic hasn't commented publicly
  • Prices didn't change: Core and Pro cost the same as before this news (below). ChangeRadar, a third-party tracker, logged the last Pro price change on Sep 10. What changed is which model your credits buy unless you choose one

How to keep using Claude in Replit Agent

  1. Be on Core or Pro. Per Replit's docs, only Core and Pro builders can choose a model manually. Starter (free) can't.
  2. In the prompt box, open Agent Mode and choose Power or Max. Free Mode always uses Replit's automatic routing and has no model list.
  3. Under Primary model, pick a Claude model. The choice applies to your next message, and you can change it any time.
  4. Turn off Auto if you always want Claude. In Power or Max, Auto is "intelligent model routing": Replit picks the model for each task. It's a paid mode that uses your credits, like any other Power or Max work.
  5. Watch Effort. Effort (Low to Max) controls how much reasoning the model does. Replit says higher Effort adds cost "up to ~2x on the toughest tasks."
  6. Don't see Primary model? Replit says model selection is still rolling out, and "the list in your Model selector is the source of truth for your account."

If you follow the default to OpenAI: check Codex's limits this week

  • The complaints: since about Oct 16, many ChatGPT and Codex users have reported limits draining far faster than usual, some within seconds of a reset. One summary post (@TokenGremlin) passed 28,000 views. Some users also report heavy usage on Pro plans
  • OpenAI's response so far: Codex lead Tibo Sottiaux is running a public 28-day challenge (Oct 5 to about Nov 1). Each day OpenAI either ships one clear improvement or does a full usage reset. Community trackers count several resets so far, the latest on Day 13 (Oct 17). Per MadRobot, OpenAI says "future resets are not guaranteed"
  • How the limits work: Plus has a rolling five-hour window plus a weekly cap. Pro "currently [has] no five-hour limit." OpenAI's estimates are ranges, not guarantees: on Plus, 5–45 local messages per five hours on GPT-6 Astra, and 15–160 on GPT-6.1 Sol. Fast mode uses your included usage 2.5x faster, and Ultrafast 8x
  • What that means for Replit: nothing directly. Replit bills Agent from your Replit credits, not your ChatGPT plan. But if you're deciding between "stay on Replit with OpenAI" and "go to Codex," this week's reports are worth knowing about. Check Settings → Usage, or run /status in the Codex CLI
