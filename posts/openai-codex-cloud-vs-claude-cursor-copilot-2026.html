OpenAI Codex Cloud vs Claude Code Cloud vs Cursor / Copilot (DevDay 2026)

On Sep 29, 2026 at DevDay, OpenAI pushed Codex past “spin up a remote sandbox” into reusable published cloud environments, a refreshed Codex CLI, ChatGPT-desktop code review, and research-preview Codex Security Cloud for GitHub scans that keep working while your laptop is closed. Same day, GitHub started rolling out GPT-6.1 Sol in Copilot for agentic coding. This post is not about NVIDIA runtime sandboxes (see Sep 29 OpenShell), not Microsoft work-agent surfaces (see Sep 28 Autopilot), and not a rehash of “where overnight agents host” (see Sep 25 Claude cloud sessions). Today’s buyer question: after DevDay, do you buy ChatGPT/Codex Cloud seats for publish-once reusable envs + Security Cloud, or stay on Claude Code / Cursor / Copilot for the same cloud-agent job.

Quick verdict

ChatGPT Plus/Pro (or Biz/Ent) shops that live in Codex: pilot reusable cloud environments now — publish a tested setup once, start isolated tasks from web/mobile/desktop while the machine sleeps; add Security Cloud (research preview) only if you already connect GitHub via Codex Cloud and will review human patches. Claude Code daily drivers: Sep 25 cloud-sessions story still stands — keep Claude Pro/Max/Team; DevDay does not force a seat swap unless your bottleneck is OpenAI-native reusable env + Security Cloud on the same account. Cursor daily drivers: keep Cursor for IDE/Projects/Rollouts; Codex Cloud is a parallel cloud host, not a Cursor replacement. Copilot shops: GPT-6.1 Sol is a model-picker upgrade (Pro+/Max/Biz/Ent, usage-based) — useful, but not the same product as Codex Cloud environments. Do not: assume Security Cloud is GA (research preview; Ent/Edu/Biz/Pro per OpenAI Help); don’t invent Codex Cloud seat prices beyond published plan VM tiers; don’t conflate reusable envs with OpenShell kernel policy (Sep 29) or Copilot Autopilot work surfaces (Sep 28).

What’s new (OpenAI DevDay + Copilot, Sep 29 2026)

  • Reusable Codex Cloud environments: Codex inspects GitHub repos, installs deps/tools, tests the setup with you, then you Publish — new tasks start from that prepared filesystem in isolated workspaces; continue from web, mobile, or desktop while the computer sleeps
  • Legacy path still exists: “Codex Cloud (Legacy)” still supports Code Review + Linear/GitHub integrations; OpenAI plans to deprecate it — migrate new work to published environments
  • Codex Security Cloud (research preview): scan connected GitHub repos on demand / schedule / new commits; build threat model, validate findings in isolation, prepare patches for human review — even offline laptop; Daybreak Blue cyber models called out in press coverage without a separate application
  • Codex CLI refresh: cleaner full-screen TUI, /agents for parallel task switching, /fork for parallel sessions with shared context, voice to start/direct tasks, worktree improvements
  • Code review in ChatGPT desktop: summaries, explore diffs, ask Codex about issues before GitHub PR / GitLab MR feedback; automatic initial reviews while you step away
  • GPT-6.1 Sol in GitHub Copilot: GA rolling out for agentic coding + terminal workflows; billed at provider list pricing under usage-based billing; available to Copilot Pro+, Max, Business, Enterprise across VS Code, Visual Studio, Copilot CLI, coding agent, github.com, Mobile, JetBrains, Xcode, Eclipse
  • Known Cloud limits (docs): no computer/browser use in cloud environments yet; GitLab and self-hosted GitHub Enterprise Server unsupported; OIDC for Enterprise by request
  • Default VM tiers (docs): Plus/Edu Plus → 2 vCPU / 8 GiB / 8 GiB disk; Pro/Business/Enterprise (and Edu/Edu Pro) → 4 vCPU / 16 GiB / 32 GiB disk; task VM state recoverable up to ~7 days after last turn

How to adopt without overbuying

  1. OpenAI-native shop — create one environment for a non-critical repo → Get started → Publish → run a short task from phone/web; only then enable Security Cloud on that same connection.
  2. Claude shop — keep Claude seats if Claude Code Projects / cloud sessions already cover overnight work; re-evaluate only if Security Cloud + reusable env on one ChatGPT bill is the missing piece.
  3. Cursor shop — keep Cursor for IDE/Rollouts; treat Codex Cloud as optional second host for GitHub.com-only repos, not a Cursor cancel.
  4. Copilot shop — enable GPT-6.1 Sol in the model picker when it appears; Biz/Ent admins: check model policy defaults. Sol ≠ Codex Cloud.
  5. Don’t confuse layers — Autopilot work surface (Sep 28) ≠ Claude overnight host (Sep 25) ≠ OpenShell runtime policy (Sep 29) ≠ this OpenAI reusable-env + Security Cloud buy.
