Claude Code Projects vs Cursor Projects (Sep 2026)

On Sep 17, 2026, Anthropic relaunched Claude Code Projects as a coordinator that scopes a goal, spins parallel cloud threads, reviews outputs, and keeps shared memory — so you stop juggling sessions by hand. Cursor shipped its own Projects coordinator on Sep 10. Here’s when to pay for Claude Pro/Max, stay on Cursor, or run both without burning your plan before lunch.

Quick verdict

Already on Claude Pro/Max + Claude Code cloud: join the Projects beta when offered — best for multi-repo goals (migrate an API across web/mobile) where Claude should open PRs and run tests in parallel. Already shipping on Cursor: keep Cursor Projects if you want IDE-native fleets, Slack/CI listeners, and model choice (including Claude models inside Cursor). Need both: Cursor for day-to-day IDE shipping; Claude Code Projects when the work is “brief a chief of staff” across repos and you’re happy in Anthropic’s cloud sessions. Free / Team waiting: Pro/Max get the Claude Code Projects beta first; Team/Enterprise and chat/Cowork Projects come later — don’t churn seats just for FOMO. Do not: assume parallel threads are free chat — each thread is a full Claude Code session and can hit usage limits fast; pick model/effort per coordinator and workers.

What’s new (Sep 17, 2026)

  • Projects redesigned: from folder/knowledge-base to a conversation — you set a goal + repo/context; Claude scopes, delegates, coordinates, reviews, assembles
  • Coordinator + threads: each thread is a Claude Code cloud session on its own branch/copy of the repo; overlaps resolve as normal PR merge conflicts
  • Subagents / loops / workflows: threads can fan out further so large assignments finish faster
  • Shared memory + library: decisions, style prefs, files, and artifacts carry across threads over days/weeks
  • Works after you leave: steer from the main project chat (or phone later); cloud keeps going
  • Rollout: beta for select Claude Pro/Max on Claude Code cloud sessions with no existing web/desktop Projects; expands to more Pro/Max this week, then Team/Enterprise and broader Claude/Cowork

  • Context: Google also opened Claude Opus 5 to its own engineers via Antigravity (quota-limited; Gemini stays default) — coding demand for Claude is not just indie blogs

How to adopt without over-buying

  1. If you already pay Claude Pro/Max and use Claude Code cloud — enable Projects when offered; start with one bounded goal (latency fix, deprecation) and watch Project-specific usage.
  2. If Cursor is already your IDE — stay on Cursor Projects for daily fleets; add Claude Pro only if you want Anthropic’s coordinator + Claude Code quality on cloud threads, not because of headline FOMO.
  3. Watch token burn — Anthropic and coverage both warn parallel threads drain plans faster; set lower effort on workers until you know the bill.
  4. Don’t confuse surfaces — One Claude Docs/Slides is for deliverables; Claude Code Projects is for shipping code; Cursor is the IDE seat.
  5. Enterprise / privacy — Cursor Projects need Cloud Agents (not Legacy Privacy Mode); Claude local threads are still coming — wait if code can’t leave your network yet.
